# SYSC4001 – Operating Systems

This repository contains my lab work, assignments, and projects completed throughout the **SYSC4001 – Operating Systems** course at Carleton University.

## Course Overview

This course explores the fundamentals of operating systems, including process management, CPU scheduling, concurrency, synchronization, deadlocks, and memory management.

## Repository Contents

This repository is organized by assignment and lab, containing source code, project files, and supporting materials.

| Folder | Description |
|---|---|
| Assignment 1 | CPU scheduling algorithms, including FCFS, Round Robin (RR), and Shortest Remaining Time First (SRTF) |
| Assignment 2 | Process synchronization using spinlocks, semaphores, and message queues |

## Tools & Technologies

- **Programming Language:** C
- **Operating System:** Linux (Ubuntu / WSL)
- **Development Tools:** GCC, Make, GDB
- **Concepts:** Process Scheduling, Concurrency, Synchronization, Deadlocks, and Interprocess Communication

## Purpose

This repository serves as a collection of my coursework and practical experience with operating system concepts, C programming, and concurrent programming.
